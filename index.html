Built to grow, without rebuilding

  • Static first: no backend, no database — fast, cheap, and easy to host anywhere.
  • Scales out: pages are stateless files served by a CDN; the index splits by collection as it grows, so a thousand pages load no slower than ten.
  • Scales up: responsive image sizes and lazy loading keep big pages light on phones.
  • Adaptable: colours, type and layout live in theme variables — a new theme is a change in one place, not a rewrite.
  • Integrable later: notes.json is the data contract. Search, auth, an API or a CMS can plug into that same contract when you ask for it — none of it is built yet.
  • Framework path, no lock-in: components (Hero, Search, Gallery, Viewer, Motion) are separated in app.js with the same data contract, so a move to Next.js + Tailwind + Framer Motion later is a port of components, not a data migration. All art and animation here is local code — no external fonts, images or scripts.
